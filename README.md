- Cut emergency alert delay by ~80% by building a Flask REST API with real-time SMS and GPS alerts (Twilio + MediaPipe)
- Led end-to-end development for a 2-member team

`YOLOv8s` `MediaPipe` `Firebase` `Twilio` `Flask`

[![Repository](https://img.shields.io/badge/Repository-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Sathya-2006/IntruderDetection)
